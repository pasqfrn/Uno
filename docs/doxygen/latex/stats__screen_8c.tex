\doxysubsection{Detailed Description}
Implementazione schermata statistiche utente. 

Mostra le statistiche dell\textquotesingle{}utente loggato\+:
\begin{DoxyItemize}
\item Partite giocate totali, vittorie, sconfitte
\item Storico partite recenti con modalita\textquotesingle{}, esito, posizione, durata
\item Scrollbar dragabile per navigare lo storico
\end{DoxyItemize}

STATISTICHE READ-\/\+ONLY\+: Questa schermata e\textquotesingle{} SOLO in lettura. Non e\textquotesingle{} possibile modificare le statistiche da qui. Le modifiche avvengono solo tramite PACKET\+\_\+\+STATS\+\_\+\+SYNC dopo ogni partita.
