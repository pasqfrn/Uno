\doxysubsection{Detailed Description}
Schermata di selezione multiplayer (host/client). 

Gestisce la creazione di stanze, l\textquotesingle{}unione tramite codice, e la risoluzione IP/codice.

NOTA\+: Il codice stanza e\textquotesingle{} di 8 caratteri esadecimali (IP in hex). Ogni dispositivo sulla LAN ha il proprio IP LAN unico, quindi il codice generato e\textquotesingle{} gia\textquotesingle{} sufficientemente unico.

La sincronizzazione del database utenti tra dispositivi LAN e\textquotesingle{} gestita separatamente dal modulo LAN Sync (UDP broadcast).
