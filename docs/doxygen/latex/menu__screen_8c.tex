Implementazione schermata menu principale. 

Gestisce il menu principale con\+:
\begin{DoxyItemize}
\item Navigazione tra profili utente
\item Accesso alle funzionalita\textquotesingle{} admin
\item Avvio partite offline (vs bot)
\item Accesso alle statistiche
\item Gestione modalita\textquotesingle{} multiplayer
\end{DoxyItemize}

Disegna la schermata del menu principale post-\/login. 

Disegna il menu principale e gestisce la navigazione.

Gestisce tutti i bottoni e sottomenu\+:
\begin{DoxyItemize}
\item Avvio partita 1v1, 1v2, 1v3
\item Accesso multiplayer (lobby)
\item Caricamento partita (sottomenu salvataggi)
\item Visualizzazione profilo e statistiche
\item Admin Panel (solo per utente "{}\+Admin"{})
\item Logout con conferma
\end{DoxyItemize}

Gestisce anche le notifiche di sistema (es. host disconnesso).
