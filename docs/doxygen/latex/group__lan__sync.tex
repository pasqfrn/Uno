\doxysection{Sincronizzazione LAN}
\hypertarget{group__lan__sync}{}\label{group__lan__sync}\index{Sincronizzazione LAN@{Sincronizzazione LAN}}


Permette a tutti i dispositivi sulla stessa LAN di sincronizzare i database utenti in tempo reale via UDP broadcast (porta 27017).  


Permette a tutti i dispositivi sulla stessa LAN di sincronizzare i database utenti in tempo reale via UDP broadcast (porta 27017). 

Funzionalita\textquotesingle{}\+:
\begin{DoxyItemize}
\item Admin panel su ogni dispositivo vede tutti gli utenti
\item Controllo unicita\textquotesingle{} username/email in tutta la LAN
\item Notifica immediata di nuovi utenti ai dispositivi connessi
\end{DoxyItemize}

ADT\+: BST per merge O(n log n).
