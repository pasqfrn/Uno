\doxysubsection{Detailed Description}
Coda dei turni\+: coda doppiamente concatenata con direzione di scorrimento. 

{\ttfamily front} è l\textquotesingle{}inizio della coda (prossimo turno), {\ttfamily rear} è la fine. {\ttfamily verso} memorizza la direzione (+1 orario, -\/1 antiorario) per Cambio Giro.
