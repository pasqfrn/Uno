\doxysubsection{Detailed Description}
Astrazione socket multipiattaforma (Windows/mac\+OS/\+Linux). 

Su Windows include winsock2.\+h e definisce le API native. Su mac\+OS/\+Linux include le socket POSIX e mappa le funzioni Windows-\/specifiche sulle equivalenti BSD/mac\+OS\+:
