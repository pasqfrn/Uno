\doxysubsection{Detailed Description}
Rendering pannello admin e modifica utenti. 

Modulo specializzato per il rendering delle schermate di amministrazione\+:
\begin{DoxyItemize}
\item FASE\+\_\+\+ADMIN\+\_\+\+PANEL\+: lista utenti scrollabile
\item FASE\+\_\+\+ADMIN\+\_\+\+MODIFICA\+\_\+\+UTENTE\+: form creazione/modifica utente
\end{DoxyItemize}

Include bug fix\+: sincronizzazione immediata admin panel, eliminazione utente loggato differita, nuovi account senza storico.
