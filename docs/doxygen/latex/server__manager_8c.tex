\doxysubsection{Detailed Description}
Gestione sessioni di gioco multiplayer. 

Modulo per la gestione delle sessioni di gioco\+:
\begin{DoxyItemize}
\item Creazione/join/leave sessioni
\item Tracking giocatori connessi e ready state
\item Liste sessioni disponibili (UDP discovery)
\item Gestione stati lobby (WAITING, IN\+\_\+\+PROGRESS, CLOSED)
\end{DoxyItemize}

Sessioni\+: array statico di \doxylink{struct_game_session}{Game\+Session} (max MAX\+\_\+\+GAME\+\_\+\+SESSIONS).

Architettura\+:
\begin{DoxyItemize}
\item \doxylink{struct_server_manager}{Server\+Manager}\+: struttura globale con array sessioni\mbox{[}\mbox{]} e contatore
\item \doxylink{struct_game_session}{Game\+Session}\+: stato completo di una stanza (giocatori, mazzo, turno)
\item Player\+Session\+: dati di un singolo giocatore nella sessione
\end{DoxyItemize}

Funzionalita\textquotesingle{}\+:
\begin{DoxyItemize}
\item Init\+Server\+Manager\+: inizializza il manager (chiamato all\textquotesingle{}avvio)
\item Shutdown\+Server\+Manager\+: chiude tutte le sessioni attive
\item Create\+Session\+: crea una nuova sessione con host
\item Add\+Player\+To\+Session\+: aggiunge un giocatore alla sessione
\item Remove\+Player\+From\+Session\+: rimuove/disconnette un giocatore
\item Start\+Session\+: inizializza il mazzo e distribuisce le carte
\item Process\+Move/\+Process\+Draw/\+Process\+Color\+Choice\+: applica mosse
\item Update\+Session\+Logic\+: aggiorna timer e stati (chiamato ogni frame)
\item Update\+Server\+Manager\+: aggiorna tutte le sessioni e rimuove chiuse 
\end{DoxyItemize}
