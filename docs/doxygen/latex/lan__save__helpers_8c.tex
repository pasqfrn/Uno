\doxysubsection{Detailed Description}
Helper per la sincronizzazione salvataggi partite via LAN. 

Modulo separato da \doxylink{lan__save__sync_8c}{lan\+\_\+save\+\_\+sync.\+c} (527 righe) per ridurre la complessita\textquotesingle{}. Contiene\+:
\begin{DoxyItemize}
\item Get\+Slot\+Path\+: costruisce path file nel formato save\+\_\+user\{ID\}\+\_\+slot\+\_\+\{N\}.dat
\item Get\+Slot\+Path\+For\+User\+: path per un dato ID utente
\item Get\+Slot\+Path\+For\+Username\+: path per dato username (scansiona ID)
\item Trova\+Recv\+: cerca o alloca un ricevitore di chunk
\end{DoxyItemize}

ADT utilizzato\+: \doxylink{struct_save_receiver}{Save\+Receiver}\mbox{[}MAX\+\_\+\+RECV\mbox{]} per accumulo chunk.

BUG FIX 4\+: Tutti i riferimenti al vecchio "{}save\+\_\+slot\+\_\+\+N.\+dat"{} sono stati migrati al nuovo formato "{}save\+\_\+user\{\+ID\}\+\_\+slot\+\_\+\+N.\+dat"{} per coerenza con \doxylink{save__manager_8c}{save\+\_\+manager.\+c}.

Fattorizzato da \doxylink{lan__save__sync_8c}{lan\+\_\+save\+\_\+sync.\+c} per modularizzazione (file \texorpdfstring{$>$}{>}450 righe).
