\doxysubsection{Detailed Description}
Gestisce registrazione, login, recupero password, eliminazione utenti e sincronizzazione Lan dell\textquotesingle{}Admin Panel. 

Caratteristiche principali\+:
\begin{DoxyItemize}
\item Database utenti con allocazione dinamica (malloc/realloc)
\item Eliminazione lazy\+: la rimozione fisica avviene solo al logout/disconnessione
\item Admin Panel real-\/time via LAN + TCP broadcast
\item BST parallelo per ricerca O(log n) dell\textquotesingle{}email 
\end{DoxyItemize}
