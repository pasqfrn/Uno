\doxysubsection{Detailed Description}
Sincronizzazione dello stato di gioco da remoto a locale. 

Questo modulo gestisce la ricezione dello \doxylink{struct_stato_gioco}{Stato\+Gioco} dal server/host e lo applica al client locale, preservando lo stato UI transiente (trascinamento carte, animazioni, chat, classifica fine partita).
