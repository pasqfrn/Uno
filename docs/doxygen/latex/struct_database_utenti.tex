\doxysubsection{Detailed Description}
Database degli utenti in memoria (allocazione DINAMICA). 

Il campo {\ttfamily lista} e\textquotesingle{} un puntatore a un array allocato con malloc/realloc. La capacita\textquotesingle{} corrente e\textquotesingle{} {\ttfamily capacita}, il numero effettivo di utenti e\textquotesingle{} {\ttfamily num\+\_\+utenti}. Quando num\+\_\+utenti raggiunge capacita, l\textquotesingle{}array viene riallocato con DB\+\_\+\+CAPACITA\+\_\+\+INIZIALE nuovi slot.
