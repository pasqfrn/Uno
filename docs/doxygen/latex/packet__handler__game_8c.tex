\doxysubsection{Detailed Description}
Gestore pacchetti di gioco per multiplayer online. 

Questo modulo gestisce TUTTI i pacchetti relativi alla logica di gioco scambiati tra host e client durante una partita multiplayer online\+:
\begin{DoxyItemize}
\item PACKET\+\_\+\+JOIN\+\_\+\+GAME\+: nuovo giocatore che si unisce alla stanza
\item PACKET\+\_\+\+GAME\+\_\+\+STATE\+: sincronizzazione stato completo (host -\/\texorpdfstring{$>$}{>} client)
\item PACKET\+\_\+\+PLAYER\+\_\+\+HAND\+: sincronizzazione mano di un giocatore
\item PACKET\+\_\+\+CHAT\+: messaggi di chat tra giocatori
\item PACKET\+\_\+\+DISCONNECT\+: gestione disconnessione
\item PACKET\+\_\+\+COLOR\+\_\+\+CHOICE\+: scelta colore dopo carta Jolly
\item PACKET\+\_\+\+MOVE\+: mossa di un giocatore (host applica e broadcast)
\item PACKET\+\_\+\+DRAW\+: pescata di carte (host applica e broadcast)
\end{DoxyItemize}

Architettura client-\/server\+:
\begin{DoxyItemize}
\item HOST\+: Riceve PACKET\+\_\+\+MOVE/\+DRAW/\+CHAT dai client, valida, applica, aggiorna lo stato e broadcasta PACKET\+\_\+\+GAME\+\_\+\+STATE a tutti.
\item CLIENT\+: Riceve PACKET\+\_\+\+GAME\+\_\+\+STATE dal host, aggiorna lo stato locale. Invia PACKET\+\_\+\+MOVE/\+DRAW/\+CHAT al host.
\end{DoxyItemize}
