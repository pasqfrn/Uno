\doxysubsection{Detailed Description}
Modulo di rete multiplayer TCP/\+UDP -\/ host e client. 

Gestisce la connessione multiplayer online per le partite UNO\+:
\begin{DoxyItemize}
\item HOST\+: crea stanza TCP, accetta client, gestisce disconnessioni
\item CLIENT\+: si connette a stanza, riceve pacchetti
\item Entrambi\+: invio/ricezione pacchetti \doxylink{struct_net_packet}{Net\+Packet} via TCP
\end{DoxyItemize}

Protocollo\+:
\begin{DoxyItemize}
\item TCP sulla porta base (27015) per il gioco
\item UDP sulla porta base+1 per discovery codici stanza
\item Ogni pacchetto e\textquotesingle{} un \doxylink{struct_net_packet}{Net\+Packet} Binario (fix 512 byte)
\end{DoxyItemize}

Architettura\+:
\begin{DoxyItemize}
\item Host ha MAX\+\_\+\+SERVER\+\_\+\+CLIENTS slot (1,2,3) + slot 0 riservato
\item Buffer separati per ogni client (recv\+Buffer\mbox{[}4\mbox{]}) per evitare corruzione di pacchetti provenienti da socket diversi
\item Modalita\textquotesingle{} non-\/blocking con WSAEWOULDBLOCK 
\end{DoxyItemize}
