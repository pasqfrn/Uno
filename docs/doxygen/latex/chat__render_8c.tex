\doxysubsection{Detailed Description}
Rendering della chat e componenti UI correlati. 

Rendering della chat in-\/game.

Modulo specializzato per il rendering della chat multiplayer, suggerimenti @mentions, invio messaggi e popup di uscita.

Funzioni\+:
\begin{DoxyItemize}
\item Draw\+Chat\+Msg\+Segmentato\+: disegna messaggio chat con tag evidenziati
\item Disegna\+Pannello\+Chat\+: pannello completo chat con cronologia e input
\item Disegna\+Popup\+Uscita\+: popup di conferma uscita partita
\end{DoxyItemize}

Estratto da \doxylink{gameplay__draw_8c}{gameplay\+\_\+draw.\+c} per ridurre la complessita\textquotesingle{} del file. Utilizza le variabili di stato definite in \doxylink{gameplay__screen_8c}{gameplay\+\_\+screen.\+c}.

Gestisce il disegno della finestra chat e dei messaggi.
