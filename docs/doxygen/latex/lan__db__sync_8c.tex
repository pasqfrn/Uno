\doxysubsection{Detailed Description}
Sincronizzazione database utenti via LAN (UDP broadcast). 

Modulo per la serializzazione, deserializzazione e merge del database utenti tramite pacchetti UDP broadcast. Gestisce\+:
\begin{DoxyItemize}
\item Serializza\+DB\+: converte db\+Utenti in buffer per trasmissione
\item Deserializza\+EMerge\+: riceve buffer e fonde con db locale
\item LAN\+\_\+\+Process\+DBPacket\+: entry point pubblico per packet handler
\item LAN\+\_\+\+Username\+Esiste\+: verifica unicita\textquotesingle{} username su LAN
\item LAN\+\_\+\+Email\+Esiste\+: verifica unicita\textquotesingle{} email su LAN
\end{DoxyItemize}

ADT utilizzato\+: \doxylink{struct_database_utenti}{Database\+Utenti} (db\+Utenti, array dinamico allocato).

Protocollo pacchetto\+: \mbox{[}\doxylink{struct_lan_packet_header}{Lan\+Packet\+Header} (magic=LAN\+\_\+\+PACKET\+\_\+\+DB + length)\mbox{]} \mbox{[}int num\+\_\+utenti\mbox{]} \mbox{[}\doxylink{struct_lan_compact_user}{Lan\+Compact\+User} x N\mbox{]}

Strategia merge (Deserializza\+EMerge)\+:
\begin{DoxyEnumerate}
\item Rimuove utenti locali non presenti nel pacchetto remoto (eccetto utente loggato e utenti in deleted\+Users)
\item Per ogni utente remoto\+: aggiorna se modificato, inserisce se nuovo
\item Protezione anti-\/ricorsione\+: dentro\+Salva\+DB evita broadcast loop
\item Dopo il merge, se siamo NET\+\_\+\+HOST, chiama \doxylink{group__network__send__admin_gac3bad81dd1e885fdb5fe711a2cc7902a}{Broadcast\+Admin\+DB()} per aggiornare i client TCP connessi in tempo reale.
\end{DoxyEnumerate}

BUG FIX 1 (Double Counting)\+: I contatori (partite\+\_\+giocate, vittorie\+\_\+giocatore, vittorie\+\_\+bot) vengono sincronizzati con "{}crescita monotona"{}\+: se il remoto ha contatori piu\textquotesingle{} alti, vengono copiati SENZA aggiungere nuovamente lo storico. Lo storico partite viene mergiato SOLO se i contatori sono gia\textquotesingle{} sincronizzati (per colmare eventuali partite mancanti). Questo evita il double counting per cui partite\+\_\+giocate veniva incrementato sia dalla copia dei contatori che dall\textquotesingle{}aggiunta delle partite storiche.

BUG FIX 2 (Storico merge affidabile)\+: La deduplica usa una chiave composta (durata, esito, modalita, posizione) PIU\textquotesingle{} username per evitare falsi positivi quando piu\textquotesingle{} giocatori hanno partite con caratteristiche simili.
