\doxysubsection{Detailed Description}
Rappresenta una singola carta UNO. 

Contiene il colore, il tipo, l\textquotesingle{}area di rendering (\doxylink{struct_rectangle}{Rectangle}), la posizione originale (per animazioni di trascinamento) e il flag di trascinamento.
