\doxysubsection{Detailed Description}
Sincronizzazione salvataggi partite via LAN (chunk UDP). 

Gestisce l\textquotesingle{}invio e la ricezione di file di salvataggio partita in chunk UDP da 1024 byte, con ricostruzione, deduplicazione e compattazione automatica.

Funzioni principali\+:
\begin{DoxyItemize}
\item Get\+Slot\+Path/\+Get\+Slot\+Path\+For\+User/\+Get\+Slot\+Path\+For\+Username\+: path helper
\item Trova\+Recv\+: cerca o alloca ricevitore di chunk
\item Invia\+Salvataggio\+Chunked\+: invia file .dat in chunk multipli
\item Ricevi\+Chunk\+: accumula chunk e ricostruisce file completo
\item Serializza\+ESpedisci\+Salvataggi\+: scandisce slot e invia tutti
\item Compatta\+Saves\+Utente\+Corrente\+: ordina cronologicamente salvataggi
\item LAN\+\_\+\+Process\+Save\+Chunk\+: entry point per packet handler
\item LAN\+\_\+\+Broadcast\+Saves\+Now\+: forza broadcast salvataggi
\item LAN\+\_\+\+Update\+Saves\+: timeout e cleanup ricevitori
\end{DoxyItemize}

ADT utilizzato\+: \doxylink{struct_save_receiver}{Save\+Receiver}\mbox{[}MAX\+\_\+\+RECV\mbox{]} per accumulo chunk. Inoltre ogni \doxylink{struct_save_receiver}{Save\+Receiver} gestisce il proprio timer (timeout 30s, reset ad ogni chunk).
