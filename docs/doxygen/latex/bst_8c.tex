\doxysubsection{Detailed Description}
Implementazione Albero Binario di Ricerca (BST) per ricerca utenti. 

ADT\+: BST con chiave = email utente (case-\/insensitive). Operazioni\+: inserzione, ricerca, rimozione O(log n) medio. Usato in \doxylink{auth_8c}{auth.\+c} come indice parallelo a db\+Utenti per ricerca O(log n).
