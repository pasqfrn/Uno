\doxysubsection{Detailed Description}
Implementazione schermata fine partita. 

Gestisce classifica, statistiche, esportazione report txt, transizioni host/client per "{}\+Gioca Ancora"{}.

Gestisce la visualizzazione dei risultati finali\+:
\begin{DoxyItemize}
\item Classifica con posizioni 1°, 2°, 3° (realistica)
\item \doxylink{struct_statistiche}{Statistiche} del vincitore
\item Pulsanti per tornare al menu o salvare
\item Visualizzazione punteggi e durata partita
\end{DoxyItemize}

La classifica viene calcolata da \doxylink{end__screen_8c_a0e745641fe838ddef9bdaf29f6c2f464}{Calcola\+Classifica()} in \doxylink{game__logic_8c}{game\+\_\+logic.\+c}.

BUG FIX COMPLETO (Fase Fine Partita)\+:
\begin{DoxyItemize}
\item RICHIESTA 1\+: Client "{}\+Gioca Ancora"{} → riportato subito in Pre-\/\+Lobby. L\textquotesingle{}Host vede notifica "{}\+Client A e\textquotesingle{} pronto in lobby"{} in basso a destra.
\item RICHIESTA 2\+: Client "{}\+Esci"{} → torna al menu, slot liberato e non riassegnato.
\item RICHIESTA 3\+: Host "{}\+Gioca Ancora"{} → torna in Pre-\/\+Lobby, slot vuoti.
\item RICHIESTA 4\+: Client "{}\+Gioca Ancora"{} DOPO che l\textquotesingle{}Host e\textquotesingle{} gia\textquotesingle{} tornato → si unisce direttamente alla Pre-\/\+Lobby con l\textquotesingle{}Host.
\item RICHIESTA 5\+: \doxylink{struct_statistiche}{Statistiche} sempre salvate, mai modificate.
\end{DoxyItemize}

BUG 4 FIX (\doxylink{end__screen_8c}{end\+\_\+screen.\+c})\+:
\begin{DoxyItemize}
\item Cliente ora usa host\+\_\+in\+\_\+prelobby per decidere se andare subito in lobby o attendere. Pattern identico a \doxylink{gameplay__draw_8c}{gameplay\+\_\+draw.\+c} per consistenza.
\item Host ora pulisce gli slot degli altri giocatori (NON host) quando preme "{}\+Gioca Ancora"{}, così la lobby mostra solo l\textquotesingle{}host come giocatore. Gli slot si riempiono man mano che i client premono "{}\+Gioca Ancora"{}.
\item Rimossa transizione immediata a FASE\+\_\+\+CLIENT\+\_\+\+LOBBY\+: ora il client va in attesa (client\+\_\+play\+\_\+again\+\_\+attesa=1) se host\+\_\+in\+\_\+prelobby e\textquotesingle{} 0. 
\end{DoxyItemize}
