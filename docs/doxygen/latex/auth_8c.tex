\doxysubsection{Detailed Description}
Implementazione modulo autenticazione e database utenti (allocazione dinamica). 

Fornisce le funzioni per la gestione del database utenti in memoria, con allocazione DINAMICA tramite malloc/realloc. Il database viene caricato da file all\textquotesingle{}avvio e salvato ad ogni modifica.

Supporta anche un BST (Binary Search Tree) parallelo per ricerca logaritmica O(log n) dell\textquotesingle{}email.
