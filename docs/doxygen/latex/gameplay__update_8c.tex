\doxysubsection{Detailed Description}
Logica di aggiornamento del gameplay UNO. 

Modulo separato che contiene la funzione Aggiorna\+Gameplay. Gestisce l\textquotesingle{}input utente, le animazioni, i turni bot, il drag-\/and-\/drop delle carte, la chat e la scelta colore.
