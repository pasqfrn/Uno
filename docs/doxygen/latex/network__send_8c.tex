\doxysubsection{Detailed Description}
Funzioni di invio pacchetti per il multiplayer online. 

Contiene le funzioni per l\textquotesingle{}invio di pacchetti TCP/\+UDP\+:
\begin{DoxyItemize}
\item Send\+Game\+State\+: invia stato completo all\textquotesingle{}host (client)
\item Broadcast\+Game\+State\+: invia stato a tutti i client (host)
\item Send\+Move/\+Send\+Draw\+: invia mossa/pescata all\textquotesingle{}host (client)
\item Send\+Chat/\+Send\+Color\+Choice\+: invia chat/scelta colore
\item Send\+Create\+Session/\+Send\+Join\+Session\+: gestione sessioni
\item Send\+Admin\+User\+Sync/\+Broadcast\+Admin\+DB\+: sincronizzazione admin
\item Send\+Play\+Again/\+Broadcast\+Host\+Return\+Lobby\+: gestione "{}\+Gioca Ancora"{}
\end{DoxyItemize}

Architettura\+:
\begin{DoxyItemize}
\item Host usa Broadcast\texorpdfstring{$\ast$}{*}() per inviare a tutti i client
\item Client usa Send\texorpdfstring{$\ast$}{*}() per inviare all\textquotesingle{}host 
\end{DoxyItemize}
