\doxysubsection{Detailed Description}
Funzioni di validazione per autenticazione e gestione utenti. 

Contiene le funzioni di validazione per\+:
\begin{DoxyItemize}
\item Email\+: controllo formato base (presenza di @)
\item Password\+: controllo lunghezza minima (8 char) e presenza maiuscolo
\item PIN\+: controllo lunghezza minima (6 char)
\item Username\+: controllo non vuoto e unicita\textquotesingle{} nel database
\item Credenziali\+: verifica login (username + password)
\item Recupero password\+: verifica email + PIN
\end{DoxyItemize}

Tutte le funzioni lavorano sul database utenti DINAMICO (db\+Utenti).
