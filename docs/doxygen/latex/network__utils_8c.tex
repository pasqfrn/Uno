\doxysubsection{Detailed Description}
Funzioni di utilita\textquotesingle{} per il modulo di rete multiplayer. 

Contiene funzioni helper per la gestione della rete\+:
\begin{DoxyItemize}
\item Gestisci\+Disconnessione\+: gestione pulita disconnessioni host/client
\item Get\+Local\+IPAddress\+: rilevamento IP locale (metodo multiplo)
\item Ip\+To\+Code/\+Code\+To\+Ip\+: conversione IP \texorpdfstring{$<$}{<}-\/\texorpdfstring{$>$}{>} codice esadecimale
\item Connetti\+Tramite\+Codice\+Stanza\+: connessione via discovery UDP
\item Shift\+Network\+Sockets\+: riorganizzazione slot dopo disconnessione
\end{DoxyItemize}

Tutte le funzioni sono state spostate qui da \doxylink{network_8c}{network.\+c} per fattorizzare il codice e separare la logica di connessione dalla logica di gioco online.
