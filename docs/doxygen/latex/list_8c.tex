\doxysubsection{Detailed Description}
Implementazione della lista concatenata per le carte UNO. 

ADT\+: Lista concatenata per la mano dei giocatori. Operazioni supportate\+:
\begin{DoxyItemize}
\item Crea\+Lista\+: inizializza lista vuota
\item Insert\+In\+Coda\+: inserisce carta in coda (per pesca)
\item Insert\+In\+Testa\+: inserisce carta in testa (per scarti)
\item Get\+At\+: ottiene carta per indice
\item Remove\+At\+: rimuove carta per indice
\item Remove\+Node\+: rimuove nodo specifico
\item Elimina\+Lista\+: distrugge tutta la lista
\end{DoxyItemize}

Caratteristiche\+: lista DOPPIAMENTE concatenata (prev + prossimo).
