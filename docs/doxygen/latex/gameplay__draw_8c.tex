\doxysubsection{Detailed Description}
Rendering del gameplay UNO. 

Contiene la funzione Disegna\+Gameplay che gestisce tutto il rendering della schermata di gioco\+:
\begin{DoxyItemize}
\item Tavolo verde e area centrale scarti
\item Mani dei giocatori (carte con texture realistica)
\item Info turno e colore attivo
\item Timer partita
\item Animazioni carte (trascinamento, pesca, scarto)
\item Scelta colore dopo jolly
\item Pulsante UNO con countdown
\item Chat multiplayer
\item Popup uscita
\item Gestione fine partita e "{}\+Gioca Ancora"{}
\end{DoxyItemize}

Funzioni delegate\+:
\begin{DoxyItemize}
\item Disegna\+Pannello\+Chat\+: rendering chat
\item Disegna\+Popup\+Uscita\+: popup conferma uscita
\end{DoxyItemize}

Fattorizzato da \doxylink{gameplay__screen_8c}{gameplay\+\_\+screen.\+c} per ridurre la complessita\textquotesingle{}.

Disegna la schermata di gioco completa.

Rendering ordinato (dallo sfondo al primo piano)\+:
\begin{DoxyEnumerate}
\item Timer partita (angolo superiore destro)
\item Info turno e colore attivo (bordo inferiore)
\item Info giocatori avversari (mano, nome, numero carte)
\item Tavolo centrale con carta scarto
\item \doxylink{struct_pila}{Pila} pesca (centro-\/sinistra)
\item Mano del giocatore umano (con hover effect)
\item \doxylink{struct_carta}{Carta} in trascinamento (effetto ombra)
\item Scelta colore (overlay per jolly)
\item Pulsante UNO (se il giocatore deve chiamare)
\item Notifiche temporanee
\item Chat (se aperta)
\item Popup uscita (sempre in primo piano)
