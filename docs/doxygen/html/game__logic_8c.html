Applica l'effetto speciale di una carta giocata.

Gestisce: cambio colore, cambio giro, salta turno, pesca carte, aggiornamento colore attivo e rotazione coda turni.

Precondizione
gioco != NULL; carta valida.
Postcondizione
Stato aggiornato con effetto applicato; notifica mostrata.
Parametri
giocoStato di gioco.
cCarta giocata.
colore_sceltoColore scelto dal giocatore (per jolly).

Applica l'effetto di una carta giocata allo stato di gioco.

Gestisce gli effetti di tutte le carte speciali:

  • CAMBIA_GIRO: Inverte la direzione del turno.
  • SALTA: Salta il giocatore successivo.
  • PIU_2: Il giocatore successivo pesca 2 carte.
  • JOLLY: Il giocatore sceglie un colore.
  • JOLLY_PIU_4: Il giocatore successivo pesca 4 carte e si sceglie un colore.
Precondizione
gioco != NULL; carta valida e giocabile.
Postcondizione
Stato gioco aggiornato con effetto applicato.
Parametri
giocoPuntatore allo stato di gioco.
cLa carta giocata con effetto speciale.
colore_sceltoIl colore scelto dal giocatore (per Jolly/JollyPiù4).

Verifica se una carta e' legalmente giocabile.

Verifica se una carta puo' essere giocata legalmente.

Regole UNO:

  • Jolly (cambiocolore/PescaQuattro): sempre validi
  • Altrimenti: match colore attivo OPPURE match tipo/valore
Precondizione
gioco != NULL; gioco->num_carte_scarti > 0.
Postcondizione
Restituisce 1 se corrispondenza colore/tipo o carta nera.
Parametri
giocoStato di gioco corrente.
cCarta da giocare.
Restituisce
1 se mossa valida, 0 altrimenti.

Verifica se una carta e' legalmente giocabile.

Controlla se il colore o il valore della carta corrisponde alla carta in cima alla pila degli scarti, oppure se e' un Jolly.

Precondizione
gioco != NULL; gioco->num_carte_scarti > 0.
Postcondizione
Restituisce 1 se mossa valida, 0 altrimenti.
Parametri
giocoPuntatore allo stato di gioco corrente.
cLa carta che si vuole giocare.
Restituisce
1 se la mossa e' valida, 0 altrimenti.
