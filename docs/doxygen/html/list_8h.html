typedef struct ListaCarte ListaCarte

Lista di carte (tipo opaco: rappresentazione interna nascosta).

La lista doppiamente concatenata mantiene puntatori a testa e coda per operazioni O(1) e la lunghezza corrente per contare rapidamente le carte in mano. Gli utilizzatori accedono ai dati solo tramite l'API pubblica.
