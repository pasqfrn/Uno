void DisegnaMenu ( StatoGioco * gioco,
FaseApplicazione * fase )

Disegna la schermata del menu principale post-login.

Disegna il menu principale e gestisce la navigazione.

Gestisce tutti i bottoni e sottomenu:

  • Avvio partita 1v1, 1v2, 1v3
  • Accesso multiplayer (lobby)
  • Caricamento partita (sottomenu salvataggi)
  • Visualizzazione profilo e statistiche
  • Admin Panel (solo per utente "Admin")
  • Logout con conferma

Gestisce anche le notifiche di sistema (es. host disconnesso).

Parametri
giocoPuntatore allo stato di gioco corrente.
fasePuntatore alla fase applicazione corrente.

Disegna la schermata del menu principale post-login.

Precondizione
gioco != NULL; fase != NULL.
Postcondizione
Menu renderizzato; fase aggiornata su interazione.
Parametri
giocoPuntatore allo stato di gioco.
fasePuntatore alla fase corrente.
