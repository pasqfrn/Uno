Descrizione dettagliata

Database degli utenti in memoria (allocazione DINAMICA).

Il campo lista e' un puntatore a un array allocato con malloc/realloc. La capacita' corrente e' capacita, il numero effettivo di utenti e' num_utenti. Quando num_utenti raggiunge capacita, l'array viene riallocato con DB_CAPACITA_INIZIALE nuovi slot.
