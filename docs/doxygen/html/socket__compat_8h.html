Descrizione dettagliata

Astrazione socket multipiattaforma (Windows/macOS/Linux).

Su Windows include winsock2.h e definisce le API native. Su macOS/Linux include le socket POSIX e mappa le funzioni Windows-specifiche sulle equivalenti BSD/macOS:

  • SOCKET -> int
  • closesocket -> close
  • ioctlsocket -> ioctl
  • WSAGetLastError() -> errno (circa)
  • INVALID_SOCKET -> -1
  • WSAStartup/WSACleanup -> noop
