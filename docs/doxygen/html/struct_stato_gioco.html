Descrizione dettagliata

Stato completo di una partita in corso.

Contiene tutti i dati necessari per gestire il gameplay: giocatori, mazzo, scarti, turno, animazioni, chat, UNO, ecc. Questa struttura viene serializzata per il salvataggio su file e per la sincronizzazione multiplayer via socket.
