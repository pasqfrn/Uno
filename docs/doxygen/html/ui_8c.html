Descrizione dettagliata

Implementazione modulo di rendering dell'interfaccia utente.

Contiene le funzioni per il disegno di elementi UI comuni:

  • CaricaTextureReali: carica tutte le texture delle carte e sfondo
  • ScaricaTextureReali: libera le texture RAM
  • DisegnaCartaRealistica: disegna una carta con texture vera
  • DisegnaBottoneMenuAnimato: bottone con effetto hover/press

Tutte le funzioni usano Raylib per il rendering. Le texture sono globali (array textureCarte[5][15]).

void CaricaTextureReali ( void )

Carica tutte le texture delle carte e lo sfondo da file PNG.

Carica textureCarte per tutti i colori e tipi, textureDorso e textureSfondo. Applica filtro bilineare per scaling di qualita'.

Precondizione
Cartelle assets/card/cards_assets/ e assets/altro/ esistono con i PNG richiesti.
Postcondizione
Texture globali caricate in RAM; filtri bilineari applicati.
Precondizione
Asset cartelle esistenti con PNG corretti.
Postcondizione
Texture caricate in RAM e filtri bilineari applicati.

Disegna una carta UNO con texture realistica e ombra.

Se coperta=1 disegna il dorso, altrimenti la texture corrispondente a colore/tipo. Applica ombra dinamica e bordo luminoso se trascinata.

Precondizione
c != NULL; r.width > 0 && r.height > 0.
Postcondizione
Carta renderizzata a schermo con ombra e bordo se applicabile.
Parametri
cPuntatore alla carta da disegnare.
rRettangolo di destinazione sullo schermo.
coperta1 per disegnare il dorso, 0 per la carta scoperta.
Precondizione
c != NULL; r dimensioni valide.
Postcondizione
Carta disegnata a schermo.
Parametri
cPuntatore alla carta da disegnare.
