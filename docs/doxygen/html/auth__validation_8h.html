int Auth_EmailGiaUsata ( const char * email,
int ignora_indice )

Verifica se un'email e' gia' in uso nel database.

Scansiona dbUtenti.lista[] alla ricerca di un'email duplicata (case-insensitive). Il parametro ignora_indice permette di escludere un utente dal controllo (utile nella modifica profilo per non bloccare il proprio indirizzo email).

Precondizione
dbUtenti inizializzato.
Postcondizione
Restituisce 1 se duplicata, 0 se disponibile.
Parametri
emailEmail da verificare.
ignora_indiceIndice dell'utente da ignorare (-1 per controllare tutti).
Restituisce
1 se gia' in uso, 0 se disponibile.

const char * password )

Cerca un utente nel database per username e password.

Scansiona dbUtenti.lista[] alla ricerca di una corrispondenza. La password viene confrontata dopo eventuale decifratura XOR.

Precondizione
dbUtenti inizializzato.
Postcondizione
Restituisce indice, -1 o -2 in base al risultato.
Parametri
usernameUsername inserito dall'utente.
passwordPassword inserita dall'utente.
Restituisce
Indice dell'utente trovato, o -1 se non trovato, -2 se password errata.

Scansiona dbUtenti.lista[] alla ricerca di una corrispondenza. La password viene confrontata in chiaro (eventuale decifratura XOR gestita esternamente).

Postcondizione
Restituisce indice, -1 o -2 in base al risultato.
